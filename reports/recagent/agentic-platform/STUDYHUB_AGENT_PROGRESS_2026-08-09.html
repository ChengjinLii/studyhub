Agentic Platform 第一阶段底座

不是简单 Chatbot，而是一套可审计、可恢复的 Agent 运行基础设施。

  • AgentKernel 支持多轮、暂停、进程重启与 Resume
  • 持久化 Run、Step、Job、Wait、Artifact 与 Event
  • Evidence Ledger、Claim-Citation 校验与无效引用拒绝
  • Snapshot Replay、Transition、Token role mask 和损坏轨迹隔离
  • 管理员专属 API，Developer、普通用户与匿名访问被拒绝
已完成

Agent 安全漏洞修复

修复结果已推送独立分支，与网站当前运行隔离。

  • 所有 Run、Event、Artifact、Resume、Cancel 均绑定 admin_actor_id
  • Worker Claim 和 Run Lease 增加续期，避免长任务被重复接管
  • Redis / DB 锁续期与释放改为所有者校验的原子操作
  • 任一 Agentic 功能启用时，缺失持久化表会启动失败而非带病运行
  • 新增并发、鉴权、租约与数据库准备测试
已完成

  • OAuth / static token、scope、客户端限流、配额和审计接口已具备

04 / OPEN WORK

还有哪些没有做

未完成项分为模型门禁、代码治理、生产接入和长期产品能力四类。

当前上线判定

不是 Agent 不能跑，而是不能可靠地跑。

现在适合做离线演示、复现实验和继续训练，不适合把 2B adapter 设为网站默认模型，也不适合用 RL 掩盖 JSON、ID 和工具前置条件问题。

01

v1.4 新数据与单 seed SFT 尚未开始

需要约 1,800 条全新、与当前 100 Gate 场景不重叠的数据，从 v1.1 seed 7703 路径重建，不从失败的 v1.3 继续训。

02

模型 Gate 仍未通过

当前严格质量 52/100、引用有效 72/100、JSON 恢复 49/100；目标是质量、引用、Replay 全部 100/100，ACL 违规为 0。

03

最终封存集没有启封

final_holdout_v2 仍保持 sealed=true、evaluated=false。只有单 seed 与三 seed 门禁全部通过后，才允许唯一一次最终评测。

04

RL 没有开始，也不应该现在开始

RL 无法可靠修复损坏 JSON、丢失 Material ID 或错误工具前置条件，当前还可能放大提前 final 偏置。

05

9B 讲解模型没有训练

现有 300 条仅用于规范验证。正式 9B SFT 前，需要清晰原文和至少 300–500 条人工确认的讲解与引用评测集。

06

SFT 与 RAG 源代码尚未版本化

本地脚本、配置、锁文件和报告还未提交 Git；2.1 GB 权重、数据与 67 MB Pilot 轨迹应继续忽略，只提交可复现代码与摘要。

07

安全分支和 Pilot 分支尚未进入 main

两个分支已上传，但 origin/main 尚不包含本轮 6 个提交。安全修复适合独立审阅；运行时约束应保持默认关闭。

08

生产灰度、监控和性能优化尚未做

尚无真实流量 A/B、Shadow 指标、质量告警或 queue 调度优化；9 个场景排队超过 60 秒，最大 126.49 秒。

09

个体层 / 群体层双层进化尚未形成闭环

已有轨迹、事件和学习对象契约，但真实用户行为采集、个体策略更新、群体聚合、版本回滚与效果归因尚未上线。

10

经营分析 Agent 尚未实现

销售周报、月报、异常趋势和运营建议仍属于后续产品线，不在本轮 2B Router 与离线 Pilot 范围内。

05 / RECOMMENDED ROUTE

接下来只走这一条路线

先把研究资产和模型协议做稳，再考虑扩大训练与接入网站。顺序不建议调换。

版本化研究代码

从当前分支切出独立 research 分支，只提交 SFT / RAG 源代码、测试、配置、模型锁与报告。继续忽略数据、权重、预测和轨迹。

构建 v1.4 数据

新增严格 JSON、搜索前置、ID / 页码保真、注入后继续与拒绝对照、evidence / compare 条件和旧能力 replay，共约 1,800 条。

单 seed 训练与 Gate

只训练一个 seed。先达到 JSON ≥99%、恢复 ≤5%、ID ≥98%、注入与权限 100%，再跑同一套 100 场景。

过线后才扩展

通过后训练三 seed，再唯一一次启封最终集，之后才讨论 Shadow、灰度和 RL。任何一步失败都回到数据与运行时契约。
