02 / Task · MDP · Algorithm

短路由，双层验证

训练把单个 Router state 视作 contextual bandit；同一状态采样 3 个动作并做组内相对优势。独立的多步环境负责验证 transition、episode 和终止条件，未伪装成完整轨迹级 GRPO。

04 / Reward · Constraints · Judge

Reward 只奖励策略拥有的能力

可由 runtime 确定性保证的内容不进入策略奖励。Reward 限幅到 [-1, 1]，激活分项按权重重新归一化；组内 reward 再标准化为 advantage。

附加惩罚：duplicate search −0.12、premature final −0.20、verbosity gaming −0.08、unsafe tool reliance −0.10。

Runtime-owned hard gates

  • 严格 JSON 与 Router contract
  • 只读工具 allowlist 与 permission boundary
  • 工具预算与 force-final
  • 可信 material_id
  • 显式 page_numbers
  • 参数范围与敏感信息阻断

这些门可以否决策略，但不产生训练梯度。
