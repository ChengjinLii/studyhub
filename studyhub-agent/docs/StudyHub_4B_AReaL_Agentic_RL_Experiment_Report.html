01

实验结论

先区分“链路跑通”“模型被更新”和“能力显著提升”三个不同命题。

已证实：4B SFT 完成 318 次更新并降低验证损失；Direct RL 与 SFT→RL 各完成 25 次 PPO/GRPO 更新、800 条 rollout、200 个完整 group；LoRA hash 均发生变化；四个 checkpoint 均完成同协议 Eval32；SFT→RL 评测完成 128/128 精确复现。
未证实：没有一个 SFT、RL 或交互效应的配对 bootstrap 95% CI 排除 0。Direct RL 的 pass@4=15.625% 是最高点估计，但 consistent@4 四组均为 3.125%，grounding 仍是主要失败面。

当前最佳工程方案

保留 SFT checkpoint 作为行为冷启动；冻结当前 Reward/环境/评测版本；下一轮优先修 citation 与 function fixture 的任务设计，而不是直接扩大 RL 步数。

当前研究判断

25-step Pilot 足以证明可训练性和暴露失败结构，不足以证明训练策略具有稳定收益。2×2 交互点估计也不支持“SFT 明显促进后续 RL”。

停止扩张的理由

两条 RL 的末段 Reward 均下降，Eval32 CI 较宽，9B 复制只会放大成本而不会先解决 verifier、citation 与任务可学性问题。

数据与 Oracle 隔离

同一开放数据源可同时服务 SFT 与 RL，但输入视图不同：SFT 看示范，RL 只看 Task、工具和环境，Gold 只进入隐藏 verifier。

2WikiMultihopQA9001,000；上下文变为 Search/Read corpus多跳检索与证据组合
QASPER600600；论文变为冻结文档库证据定位与 citation

SFT Split

2,550 train / 300 validation / 150 sealed test；按 paper、source、tool template group 切分；五个来源共 3,000 条。

RL Split

2,000 train / 400 validation；SFT source/group overlap、RL train/validation group overlap 均为 0；公开任务禁止 Oracle 字段。

可见信息

Policy 只看到问题、allowed tools 和工具返回；gold answer、expected calls、supporting facts、gold source IDs 不进入 rollout context。

仍有限制

这是开放数据适配的冻结环境，不等价于真实 StudyHub 在线用户分布；Eval32 是开发集，不是 sealed final benchmark。

04

4B SFT

SFT 目标是稳定协议与行为先验，不承担搜索策略优化。Loss 仅作用于 assistant token。

L_SFT = − Σ m_t log pθ(y_t | x, y<t) / Σ m_t
m_t = 1 only for assistant action/answer tokens

训练配方

BF16；LoRA r=16、α=16；目标模块 o/gate/up/down；Adam；cosine LR 2e-5；2 epochs；gradient checkpointing。

数据长度

assistant token 占比 18.87%；输入 token p50=238、p95=1,098、max=2,021；没有依赖训练中联网加载。

资源

318/318 updates；GPU 峰值 38,113 MiB，峰值利用率 62%；证据包状态 COMPLETE。

07

失败结构与训练诊断

平均 Reward 掩盖了三个任务族完全不同的问题；下一轮应按 family 修数据与 verifier，而不是统一加训练步数。

SFT→RL Pilot familyRewardZero-var主要信号判断
Evidence grounding-0.348615.88%149 missing citation；强制收尾 39.22%有组内方差，但证据链和引用未学会
Function calling0.3516817.86%invalid tool call 53.13%Reward 高不等于协议稳定，fixture/参数仍困难
Search multihop-0.0108664.52%task success 96.84%，citation -0.8513答案判定过易、引用约束失败，学习信号稀薄

没有熵崩塌

SFT→RL entropy mean=0.4096，末段未向 0 收缩；Direct RL mean=0.3341。当前只能报告“未观察到”，不能制造事故故事。

有 Zero-variance 风险

SFT→RL 73/200 groups 无方差，Search family 达 64.52%。这会让组内 advantage 缺少方向，是当前最明确的 RL 数据/Reward 风险。

Reward 没有改善

SFT→RL 前 5 step 均值 0.0091，末 5 step -0.0845；Direct RL 也从 0.0877 降至 -0.0225。不能用“训练稳定”替代“效果提升”。

上下文与长度

SFT→RL 2,863 interactions；sequence p95=3,174、max=4,096，仅 9 条触顶；135 条强制收尾均关闭 thinking；14 条压缩，10 条紧急压缩被记录为诊断信号。

策略新鲜度

policy version 0–24 均有记录，无 mixed-policy records，trajectory reuse=1；当前 pinned proxy 没有暴露逐 rollout seed，这一项保留为边界。

10

可以说什么，不能说什么

这是 Goal Pack 的证据合同在最终报告中的落地。

可以陈述

完成 4B SFT 与两条 25-step Agentic RL Pilot；训练/工具/环境/Reward/LoRA 发布链路可复现；Eval32 显示点估计差异但无显著总体增益；已定位 citation、zero variance、function invalid calls 等具体瓶颈。

不能陈述

不能说 SFT→RL 显著优于其他方案；不能把 Eval32 当 sealed benchmark；不能声称 9B、DAPO、PPO、OPD/KDRL 已训练；不能把双卡 Pilot 外推为大规模集群经验。

下一轮最小实验

先固定模型，修正 Search 的 citation/verifier 契约与 Function fixture；重做小型 Reward calibration；降低 Search zero-variance；再以同一 Eval32 + 新 sealed set 运行 200-task Pilot。

9B 条件

只有当 4B 的 family-level 失败得到修复、Pilot 显示可学习趋势且 Eval CI 开始收窄时，9B 复制才有信息增益。当前不启动 9B 是实验决策，不是遗漏。
