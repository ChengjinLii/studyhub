两张 H100 是一个资源池

选择标准不是某张卡的瞬时利用率，而是在训练正确性和稳定性约束下的 end-to-end time-to-quality。

1 + 1 Sync

一张 actor/ref，一张 SGLang。作为必须测量的真实 baseline。

  • 优点：边界简单、已有历史
  • 风险：phase idle、显存失衡
B

2-GPU Colocated

Update 用 FSDP2，rollout 用 SGLang TP2，阶段间 memory saver / weight refresh。

  • 候选：fsdp:d2
  • 候选：sglang:d1t2p1
  • Qwen3.5 LoRA 最小更新 Gate 已通过；完整 profile 待执行
C

Async

仅当 A/B 存在实质 idle，且 pinned AReaL 能可靠记录 policy age 时测试。

  • 必须报告 ratio tail / KL
  • 吞吐提升不能掩盖 staleness
