# Agent Architectures & AgentBench v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a hook-based architecture layer with five agent architectures, build StudyHub AgentBench v3 (synthetic snapshot, templated tasks, deterministic grading, statistics), run the 9-config comparison on Qwen3.5-4B/9B, and commit the analysis report to main.

**Architecture:** `EpisodeRunner` gains four hooks (`on_start`, `before_step`, `on_final`, `select_policy`) driven by an `Architecture` object and a mapping of named policy clients; the five architectures are small classes in `studyhub_agent.architectures`. The benchmark lives in `studyhub_agent.bench` (task model, fault-injection environment, batch runner, statistics) plus `graders/bench.py`, with data under `benchmarks/agentbench-v3/` and generator/report scripts under `scripts/bench/`.

**Tech Stack:** Python 3.12, pydantic v2, httpx, SGLang (serving per `scripts/serving/README.md`), pytest, ruff, import-linter; matplotlib for report figures (dev/report extra).

**Spec:** `studyhub-agent/docs/specs/2026-09-26-architectures-benchmark-design.md`

## Global Constraints

- Architectures: exactly `react`, `react_verify`, `plan_execute`, `react_context`, `cascade`; versions `1.0`.
- Models: Qwen3.5-4B (`small`) at `/data/chengjin/studyhub/models/P1/Qwen3.5-4B`, Qwen3.5-9B (`large`) at `/data/chengjin/studyhub/models/P1/Qwen3.5-9B`; cascade = small→large.
- Contract invariants from sub-project 1 hold: tools, system prompt, thinking, template never change mid-episode; every injected text comes from the prompt registry; contract hash additionally covers `architecture_id@version`, the architecture's prompt texts, and each policy key's model id + tokenizer revision.
- `Episode.messages` always keeps the full uncompressed history; `before_step` only changes what is sent.
- Observation `payload` = model-facing content (unchanged); new `details` = structured data never rendered to the model.
- Benchmark data: synthetic snapshot generated by self-hosted Qwen3.5-9B with fixed seed; no real personal data; Chinese ≥ 80% of task text.
- Splits: Dev 240 tasks, Test 160 tasks, grouped by school so no material appears in both; Test run once for the final report; every run appends to `benchmarks/agentbench-v3/EXPOSURE.jsonl`.
- Grading is deterministic only (no LLM judge); grader calibration set must score 100% before official runs; oracle must solve 100% of tasks.
- Sampling for experiments: temperature 0.7, top_p 0.95, 3 samples per task, fixed seeds, thinking off; budget max_turns 12, max_tool_calls 16, max_context_tokens 16384, max_new_tokens 2048.
- Statistics: pass@1, pass^3, paired bootstrap (10,000 resamples, 95% CI) vs same-model `react`, McNemar on per-task majority, Holm correction, MDE reported.
- Cascade weighted cost: 4B tokens ×1.0, 9B tokens ×2.25.
- Layers (import-linter): `bench` > `architectures` > `runtime` > `environments` > `tools` > `guardrails` > `contracts`; `graders` imports only `contracts`; `bench` may import `graders`.
- Raw episode JSONL stays on the server under `/data/chengjin/studyhub-agent-runs/<run_id>/`; only summaries and figures are committed.
- Coverage of `studyhub_agent` ≥ 80%; ruff clean on src/tests/scripts; wheel CI step stays green.
- Commit messages conventional, English, no Co-Authored-By; author ChengjinLii.
- Shared GPUs: check `nvidia-smi`, stay within free memory, stop only your own processes; never kill local processes listening on ports (the SSH ControlMaster is one).

```python
from dataclasses import dataclass, field
from typing import Any, Protocol, Sequence

from studyhub_agent.contracts.episode import AssistantTurn, EpisodeSpec, Message, Observation


@dataclass(frozen=True, slots=True)
class Accept:
    pass


@dataclass(frozen=True, slots=True)
class Continue:
    feedback: tuple[Message, ...]
    reason: str


FinalDecision = Accept | Continue


@dataclass
class RunContext:
    spec: EpisodeSpec
    turns: list[AssistantTurn]
    observations: list[Observation]
    policy_key: str = "small"
    tool_calls_used: int = 0
    parse_errors: int = 0
    trace: dict[str, Any] = field(default_factory=dict)

    @property
    def read_pages(self) -> frozenset[tuple[int, int]]:
        pages = set()
        for obs in self.observations:
            for material_id, page in obs.details.get("read_pages", []):
                pages.add((int(material_id), int(page)))
        return frozenset(pages)


class Architecture(Protocol):
    architecture_id: str
    version: str
    prompt_keys: tuple[str, ...]

    def on_start(self, ctx: RunContext) -> Sequence[Message]: ...
    def before_step(self, ctx: RunContext, messages: Sequence[Message]) -> Sequence[Message]: ...
    def on_final(self, ctx: RunContext, turn: AssistantTurn) -> FinalDecision: ...
    def select_policy(self, ctx: RunContext) -> str: ...


class ReactArchitecture:
    architecture_id = "react"
    version = "1.0"
    prompt_keys: tuple[str, ...] = ()

    def on_start(self, ctx: RunContext) -> Sequence[Message]:
        return ()

    def before_step(self, ctx: RunContext, messages: Sequence[Message]) -> Sequence[Message]:
        return messages

    def on_final(self, ctx: RunContext, turn: AssistantTurn) -> FinalDecision:
        return Accept()

    def select_policy(self, ctx: RunContext) -> str:
        return ctx.policy_key
```

- `ContractInputs` gains `architecture: str = "react@1.0"`, `architecture_prompts: tuple[PromptTemplate, ...] = ()`, `models: tuple[tuple[str, str, str], ...] = ()` (policy key, model id, tokenizer revision); all enter the hash document.

Episode gets `architecture`, `architecture_trace=ctx.trace`, `models`.
- Update `.importlinter` layers to `studyhub_agent.bench`, `studyhub_agent.architectures`, `studyhub_agent.runtime`, ... (create an empty `studyhub_agent/bench/__init__.py` here so the contract resolves).
