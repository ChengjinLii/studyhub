用户学习助手已有检索、工具循环、记忆和证据约束； 管理端 Agentic Platform 已有 LangGraph 状态机、训练数据策略与奖励事实。 训练沿用现有运行时边界，不重写 Hermes 核心。

Ready

结构化工具轨迹

工具名、参数、观察、最终回答已可记录；训练导出已支持 loss mask，只训练 assistant action 与 final。

Ready

奖励事实与数据分级

成功、格式、证据、重复调用、成本等事实已有表达；公开/合成可训练，个人与受限数据禁止导出。

Gap

固定评测与真实反馈

仍需扩大检索金标、构建 500–1,000 个 Agent 场景，并验证奖励分数与人工判断的一致性。

负责资料搜索、证据读取、题目讲解、学习计划与个体记忆。个体进化应更新 profile / memory，不应给每个用户单独改权重。

03 / TRAINING JOBS

SFT 与偏好训练任务

每个任务对应当前代码中的具体职责和验收指标。第一阶段评估格式、证据和工具调用，后续阶段评估回答风格与长链路收益。

P0 · SFT

路由与工具策略

训练严格 JSON、是否检索、工具选择、参数构造、澄清问题和越权拒绝。

模型
Qwen3.5-2B；Qwen3-4B 作稳定控制组
数据
10k–30k 条，来自合成轨迹 + 失败轨迹修复 + 人工抽检
门槛
Schema ≥ 99.5%，工具名 ≥ 98%，越权召回率优先
P0/P1 · SFT

证据化学习讲解

训练中文分步讲解、页码引用、证据不足时的克制回答和可执行学习计划。

P1 · SFT

验证器与 AI 审核

识别无效 material_id、伪页码、错误标签、低质描述、广告与链接风险，并输出可校准置信度。

模型
Qwen3.5-2B
数据

P1 · DPO

教学偏好优化

用 chosen / rejected 对齐讲解层次、简洁度、追问质量和证据忠实度，不把主观风格塞进奖励函数。

模型
Qwen3.5-4B 或 9B
数据
5k–15k 对，至少双人抽检高风险子集
门槛
盲测胜率提升，同时事实与工具指标不得回退
检索与推荐任务

检索模型应在 ≥1,000 组 query–positive–hard-negative 后做对比学习与 pairwise reranker 微调； 推荐系统先做监督排序，收齐曝光 propensity、点击、收藏、下载、接受/跳过后再考虑 contextual bandit。

04 / OFFLINE RL

离线 RL 目标与范围

RL 在固定资料快照和无副作用工具中优化搜索效率、证据命中率和任务完成率。 生产数据库与真实用户会话不进入 rollout 环境。

STEP 01冻结评测集场景、资料快照、预期证据与失败条件
STEP 02SFT 热启动先保证格式、工具和权限边界稳定
STEP 03DPO 对齐优化教学偏好，不改变环境策略
STEP 044B RL PilotGRPO 控制组，GSPO 稳定性对照
STEP 05Shadow只旁路评测，不自动切换用户流量

Reward 组成与数据来源

R = success + format + action_valid
  + evidence_supported + rank_delta
  − invalid_citation − duplicate_tool
  − void_observation − tool_cost
  − permission_violation

观察、系统提示和用户 token 全部 mask；只训练 assistant 的 action 与 final。 RL batch 混入 SFT replay，防止多轮训练后工具格式崩塌。

05 / 8-WEEK PATH

实施顺序

执行顺序为冻结数据与评测、锁定依赖、运行训练、比较结果。Qwen3.5 相关实验固定 Transformers、vLLM、TRL / veRL 版本， 并使用现有 Qwen3-4B 完成端到端控制实验。

WEEK 1

冻结基线

固定数据快照、500+ 场景、版本与当前模型零样本成绩。

WEEK 2–4

SFT 实验

2B 路由/审核与 9B 讲解并行；抽检教师数据和难例。

WEEK 5–6

DPO + 控制 RL

偏好盲测；现有 Qwen3-4B 跑通离线 GRPO 控制组。

WEEK 7–8

迁移与旁路

Qwen3.5-4B 对比 GRPO / GSPO；仅 shadow，不接管线上。

实验原则

  • 每次训练都与未微调基座、教师模型和确定性规则做消融对照。
  • 个体学习状态写入可删除的 memory/profile，不写入模型权重。
  • 群体反馈只做匿名聚合和周期性 adapter，经过离线 Gate 后再做灰度评测。
  • 保留原始 token IDs、tool observations 与 loss mask，保证可复现。

排除项

  • 不训练内部 CoT；教师生成内容经抽检后才能进入训练集，且不标记为人工金标。
  • RL rollout 不访问真实网站、生产数据库或付费资料。
  • 首轮不采用 PPO、GiGPO、TIPS 或多 Agent RL，先完成 GRPO / GSPO 对照。
  • 推荐、审核、检索和讲解使用独立任务定义与 adapter。
