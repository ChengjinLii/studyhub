# StudyHub 品牌宣传片：脚本、分镜与音画节奏表

版本 v2（2026-10-10，含审阅修复轮）。时间与 `src/cues.json` 一致；画面和声音都从这个文件读取时间点。竖屏与横屏（1920 × 1080）共用这些时间、文案和声音；横屏版式见 `src/landscape/layout.js`。

## 1. 核心创意

**一页笔记的旅程。** 一张笔记卡贯穿全片：先是群里没人回应的“求资料”，然后在 StudyHub 汇聚成有序的资料库，被搜到、被下载；之后同学把自己的笔记投稿，这一份笔记复制、分发，点亮更多同学；最后笔记的两条横线竖起来，变成 StudyHub 机器人 Logo 的两只眼睛。

**形状语法。** StudyHub Logo 是深色圆角方块加两只白色胶囊眼睛（`frontend/public/icons/studyhub-app.svg`）。笔记的文字行也是胶囊。全片的角色、气泡、卡片、按钮、手机和 Logo 都由同一个“圆角矩形”参数族构成（圆 → 胶囊 → 卡片 → 页面 → Logo）。形变只插值中心、宽、高和圆角，所以轮廓不会打结或自交。

**记忆点。** 15–20 秒：一份笔记一分为多，飞向一圈圈同学，同学的胶囊眼睛变成笑眼。26.2–27.0 秒：笔记的横线竖起，变成 Logo 的眼睛。
